# Scratch2Build – Week 3: Tuesday Offline Lab

## Overview
In this lab, we will use JavaScript to make the FCAI Activity Portal interactive. You will practice updating the page dynamically and responding to user input.

## Block 1: Dynamic Event Submission
Build a form that lets users submit an event.

You will practice:
- Selecting HTML elements with the DOM.
- Handling form submission with `addEventListener()`.
- Preventing the default page reload with `event.preventDefault()`.
- Validating user input and showing error messages.
- Creating and displaying event cards dynamically.

**Your task:** Complete the TODOs in `block-1-core-lab/script.js`. Validate the form fields, show useful feedback, and add a valid event to the page without reloading it.

## Block 2: Extension Challenge
Add an interactive search and category filter to the event listings.

**Your task:** Complete the TODOs in `block-2-extension/script.js`. Search as the user types, filter by category, and make both filters work together without reloading the page.

## Before You Finish
- Test valid and invalid form submissions.
- Test search with different keywords.
- Test every category and combined filters.
- Check that the page does not reload during these actions.

## Project Structure
- `block-1-core-lab/` – Dynamic event submission and real-time form validation.
- `block-2-extension/` – Live search and category filtering.
